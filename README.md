# B2B SEO Workflow

这份仓库用于搭建并运行一套 **B2B SEO 工作流**，目标是从“关键词研究”走到“线索转化”，形成可复用、可量化、可迭代的增长系统。

## 快速开始

1. 阅读主流程文档：`docs/b2b-seo-workflow.md`
2. 复制模板到你的项目空间并填写：
   - `templates/keyword-cluster-template.csv`
   - `templates/content-brief-template.md`
   - `templates/seo-experiment-log-template.csv`
3. 按照文档中的周节奏执行（Sprint 节奏）
4. 每周复盘一次、每月做一次策略迭代

## 推荐执行节奏

- **周一**：关键词/专题池更新、优先级评审
- **周二到周三**：内容 Brief + 写作/制作
- **周四**：SEO 上线检查 + 发布
- **周五**：数据复盘 + 实验结论沉淀

## 仓库结构

- `docs/b2b-seo-workflow.md`：完整工作流、RACI、KPI 与 SOP
- `templates/keyword-cluster-template.csv`：关键词聚类与优先级模板
- `templates/content-brief-template.md`：内容任务模板
- `templates/seo-experiment-log-template.csv`：实验与优化记录模板
