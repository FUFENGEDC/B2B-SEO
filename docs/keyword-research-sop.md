# 关键词调研 SOP

> 适用场景：B2B 内容生产前的关键词研究阶段
> 对应工作流：`docs/content-creation-sop.md` Step 1-3
> 执行时间参考：完整调研约 2-4 小时 / 快速启动约 30 分钟

---

## 一、关键词调研的 4 个核心流程

### 流程 1：明确目标受众的需求

**步骤**：

1. 先定义你的核心用户是谁
   - 例如：预算有限的年轻家庭主妇、跨境电商从业者
2. 明确用户为什么要买你的产品或服务（他们想解决什么痛点）
3. 拆分用户在不同阶段会关心的问题：

| 阶段 | 用户关心的问题类型 |
|---|---|
| 购买前 | 产品是什么？有哪些选择？哪个最好？ |
| 购买中 | 价格如何？怎么下单？有没有折扣？ |
| 购买后 | 怎么用？出了问题怎么办？如何维护？ |

4. 用真实渠道验证，不要只靠猜，可以从这些地方找需求：
   - 亚马逊 / 电商平台评论区
   - Reddit / Quora / 专业论坛
   - 你自己网站或竞品网站的 Q&A
   - 客服聊天记录

5. 把收集到的问题整理成**"用户真实需求清单"**（至少 10 条）

---

### 流程 2：确定关键词意图

**步骤**：

1. 先列出一批潜在关键词
2. 判断每个关键词背后的搜索目的
3. 将关键词分为 4 类：

| 意图类型 | 识别信号词 | 匹配内容形式 |
|---|---|---|
| 信息型 | What is / How to / Guide / Explain | 指南、FAQ、科普文章 |
| 导航型 | 品牌名 / 官网名 / 产品名 | 官网页、品牌页 |
| 商业型 | Best / Top / Review / Comparison / vs | 对比页、评测页、选购指南 |
| 交易型 | Price / Discount code / Where to buy / Order | 产品页、落地页、集合页 |

4. 最后确认：**这个关键词适合写什么内容**，而不是只看搜索量

---

### 流程 3：寻找合适的关键词

**步骤**：

1. 在完成用户需求分析后，开始正式找词
2. 用多种方法挖词，而不是只靠一个工具（详见第二节"5 大方法"）
3. 先广泛收集，再筛选
4. 后续再根据搜索量、竞争度、意图做决策

**优先级筛选标准**：

| 维度 | 目标值 | 说明 |
|---|---|---|
| 月搜索量 | > 100 | 行业词可放宽 |
| 关键词难度 KD | < 30 | 新站建议 < 20 |
| 搜索意图 | 信息型 / 商业型 | 与内容匹配 |
| 商业价值 | 高 | 能带来线索或转化 |

---

### 流程 4：生产和优化内容

**步骤**：

1. 根据关键词意图决定内容类型：
   - 信息型词 → 博客、指南、FAQ
   - 商业型词 → 测评页、对比页、推荐页
   - 交易型词 → 产品页、活动页、落地页

2. 发布后继续优化，不是写完就结束：
   - 30 天后：检查收录状态、排名变化
   - 60 天后：评估 CTR，优化 Meta Title/Description
   - 90 天后：评估转化，决定是否更新内容或加内链

---

## 二、寻找关键词的 5 大方法

### 方法 1：基于用户需求逆向推导

**步骤**：

1. 把自己代入成目标用户，模拟用户脑中的搜索过程
   > 例：初步想法"我想买折叠电动自行车" → 第一搜：`folding ebike` → 第二轮问题：哪个好？便宜吗？续航怎么样？

2. 定义目标用户画像，梳理他们的核心痛点和需求
3. 通过评论区、论坛、客服信息等渠道，整理出 **10 个最常见问题**
4. 把这些问题改写成用户会搜索的句子 → 这些句子就是你的**第一批关键词**

---

### 方法 2：AI 辅助快速拓展

**步骤**：

1. 准备一个种子词（例如：`folding ebike`）
2. 打开 Gemini 或类似 AI 工具，输入明确指令：

```
请列出 20 个与"[种子词]"相关的长尾关键词，
并按信息型、商业型、交易型分类。
```

3. 获取 AI 返回的关键词清单
4. 再用"种子词 + 修饰词"继续扩展：

| 组合方式 | 示例 |
|---|---|
| 产品 + 场景 | folding ebike for commuting |
| 产品 + 痛点 | folding ebike battery life |
| 产品 + 用途 | folding ebike for seniors |

5. 把结果整理成分类关键词库

---

### 方法 3：竞品关键词反查

**步骤**：

1. 先找出 3–5 个主要竞品
   > 方法：直接去 Google 搜你的核心词，看前排的网站是谁

2. 把竞品域名输入 **SEMrush**：
   - 打开"域名概览"
   - 进入"自然搜索关键词"详情页
   - 查看竞品有哪些关键词在带来自然流量

3. 先排除品牌词（过滤掉包含竞品品牌名的词）

4. 重点找**竞品排名在 5–20 位之间**的词
   > 这类词往往有搜索量，但对手垄断还不强，是机会词

5. 把这些词整理成你的**机会词库**

---

### 方法 4：用 Google 自带工具挖词

#### 4.1 Google Autocomplete（下拉菜单）

**步骤**：

1. 打开 Google，输入你的种子词（例如：`folding ebike`）
2. 继续在后面依次加字母 a、b、c……
3. 记录所有有价值的自动补全词：
   > 例：`folding ebike amazon` / `folding ebike battery` / `folding ebike cheap`
4. 整理为扩展关键词清单

#### 4.2 SERP 底部相关搜索

**步骤**：

1. 搜索目标关键词
2. 滑到搜索结果最底部
3. 看"相关搜索 / People also search for"
4. 提取相关主题和关联问题
5. 用这些词扩充内容方向

#### 4.3 Google Keyword Planner

**步骤**：

1. 进入 Google Ads 后台
2. 打开关键词规划师
3. 输入你的种子词
4. 查看 Google 给出的相关关键词和数据
5. 用这些数据做后续筛选

---

### 方法 5：专业关键词工具深度分析（SEMrush）

**步骤**：

1. 打开 SEMrush，进入 **Keywords Explorer**
2. 输入种子词
3. 打开 **Keyword ideas / 关键词建议报告**
4. 使用筛选器：

| 筛选条件 | 推荐设置 |
|---|---|
| KD（难度）| < 30 |
| Volume（搜索量）| > 100 |
| 包含特定词 | "best" / "review" / "guide" |
| 排除词 | 竞品品牌名 |

5. 从几千个词里筛出几十个高价值关键词
6. 优先选择**"有量 + 竞争可控 + 意图明确"**的词

## 三、高效关键词调研的完整执行顺序

```
Step 1  用户需求逆向推导（先定方向）
   ↓
Step 2  AI 辅助拓展（拓思路）
   ↓
Step 3  Google 自带工具（找灵感）
   ↓
Step 4  竞品分析（看别人怎么做）
   ↓
Step 5  专业工具筛选（最终决策）
```

---

## 四、精选摘要（Featured Snippet）的 3 种做法

### 方法 1：文本精选摘要

**步骤**：

1. 先提出一个明确问题（用 H2 或加粗展示）
2. 紧接着在问题后，用 1–2 句陈述句直接回答
3. 回答控制在 **40–60 个单词**左右
4. 注意：
   - 不要用第一人称
   - 不要带营销腔

---

### 方法 2：列表精选摘要

**步骤**：

1. 用包含关键词的 H2 标题提出问题
2. 直接用列表列出答案
3. 或者用 H2 做总标题，再用 H3 逐个列出产品/服务
4. 特别适合：Top N、推荐、步骤型内容

---

### 方法 3：表格精选摘要

**步骤**：

1. 用表格标签组织数据
2. 明确表头
3. 用 `<caption>` 提示表格主题（让 Google 更容易理解表格内容）

---

## 五、深度解析 SERP 的方法

### Step 1：战场侦查（SERP Analysis）

**步骤**：

1. 用浏览器**无痕模式**搜索你的核心关键词（或借助插件切换到目标国家 IP）
2. 记录 SERP 上出现了哪些元素：

| SERP 元素 | 出现了吗？| 占据位置 |
|---|---|---|
| 广告 | | |
| AI Overview | | |
| 精选摘要 | | |
| 自然排名 | | |
| People Also Ask | | |
| 论坛内容（Reddit 等）| | |
| 知识面板 | | |

3. 判断谁占据了最重要的位置
4. 识别当前 SERP 的内容主形态

---

### Step 2：策略制定（Strategy Formulation）

**步骤**：

1. 根据 SERP 结果，判断应该做什么类型的内容：

| SERP 观察 | 对应策略 |
|---|---|
| 以长文评测为主 | 做更深度的长文 |
| 对手拿了精选摘要 | 优化结构去抢"第 0 位" |
| 对手外链强 | 增加外链建设 |
| PAA 问题多 | 在 FAQ 章节覆盖这些问题 |
| Reddit 出现在首页 | 去 Reddit 发帖 / 引用真实用户声音 |

2. 把观察转化成明确执行动作

---

## 六、30 分钟启动第一篇内容的方法

### 步骤一：选定战场和关键词（5 分钟）

1. 先选主题（例如：10 款最强耐阴植物推荐）
2. 确定核心关键词
3. 用 Google 下拉和相关搜索找长尾关键词
4. 把这些真实需求先记下来

---

### 步骤二：侦查对手并制定大纲（10 分钟）

1. 搜索核心关键词，打开前 5 名结果
2. 不细读，只分析结构：
   - 他们推荐了什么
   - 用了哪些 H2/H3
   - 有没有覆盖 PAA

3. 在此基础上写自己的大纲：

```
H1  主标题
H2  引言（直接回答核心问题）
H2  清单 / 核心内容
    H3  第 1 项
    H3  第 2 项
    H3  第 N 项
H2  FAQ
H2  总结 + CTA
```

---

### 步骤三：内容填充与优化（15 分钟）

1. 按大纲快速写初稿（可借助 AI，但不能直接照搬）
2. 一定要加入独特价值：
   - 个人经验
   - 客户反馈
   - 自己拍的图片
   - 实操建议

3. 做基础 SEO 优化：
   - 核心关键词放进标题
   - 核心关键词放进首段
   - 核心关键词至少进一个小标题
   - 长尾词自然融入正文
   - 图片配 ALT 文本

4. 发布后继续迭代优化

---

## 七、语义覆盖的落地写法

### 一篇文章的语义覆盖结构

```
H1  主问题
    ↓ 开头 1 段直接回答
H2  定义 / 原理
H2  结构 / 组成
H2  核心好处
H2  对比
H2  应用场景 / 选型建议
H2  采购 / 技术参数
H2  FAQ
```

---

### 找语义覆盖点的 5 个来源

| 来源 | 操作方式 |
|---|---|
| Google 前 10 名 | 看标题和小标题，提取高频主题 |
| People Also Ask | 直接转化为 FAQ 问题 |
| 竞争对手文章目录 | 提取他们覆盖的模块 |
| 客户真实问题 | 来自客服记录、评论区 |
| 行业术语和标准 | 查行业白皮书、认证标准文件 |
