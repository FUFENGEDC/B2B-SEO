# B2B SEO 内容生产 SOP（12 步标准流程）

> 适用场景：产品型文章集群 / 工程类文章集群 / 认证类文章集群
> 目标：生产满足 EEAT + GEO + 结构化数据要求的高转化 B2B 内容

---

| 一级集群类型          | 核心要回答的问题          | 典型标题方向                                                                                                                                          | 适合覆盖的内容                    | 漏斗阶段        | 商业价值           |
| --------------- | ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | ----------- | -------------- |
| 认知教育型集群         | 这是什么？             | What is X, X meaning, X explained, X types, X uses                                                                                              | 定义、分类、基础知识、用途说明            | TOFU        | 拉新流量、做主题入口     |
| 选型决策型集群         | 我该怎么选？            | How to choose, buying guide, selection guide, best X for Y, what to consider when buying X                                                      | 选购标准、采购要点、适配建议、不同需求推荐      | MOFU        | 很强，适合导向产品页/服务页 |

## Step 1：调研文章集群标题

**目标**：为下面8种集群类型各规划 5-10 篇文章标题。

**操作步骤**：
1. 使用 `templates/article-cluster-research-template.md` 进行标题调研
2. 从以下维度出发构建标题：
1. 认知教育型集群

回答“这是什么”。

适合写：

What is X?
X meaning
X explained
X types
X uses

这类文章负责拉新流量、做主题入口。

2. 选型决策型集群

回答“我该怎么选”。

适合写：

how to choose
buying guide
selection guide
best X for Y
what to consider when buying X

这类很适合 B2B，商业价值很高。

3. 对比替代型集群

回答“X 和 Y 有什么区别”。

适合写：

X vs Y
compare
alternative
pros and cons
which is better

这类经常带强意图，转化也不差。

4. 规格标准型集群

回答“参数、标准、技术要求是什么”。

适合写：

specifications
dimensions
standards
tolerance
testing method
technical requirements

这个可以覆盖你原来“工程类”的很大一部分。

5. 应用场景 / 解决方案型集群

回答“它适合谁、适合什么项目”。

适合写：

best for hotel
for supermarkets
for retailers
for e-commerce sellers
for hospitals / villas / contractors

这个特别适合你这种 B2B 制造商网站。

6. 工艺质量 / 问题排查型集群

回答“怎么做、为什么会出问题、怎么解决”。

适合写：

manufacturing process
quality control
common defects
troubleshooting
why does X happen
how to avoid X

这个才是真正更完整的“工程类”。

7. 认证合规型集群

回答“要符合什么认证、标准、法规”。

适合写：

certification explained
compliance requirements
OEKO-TEX / CE / REACH / ASTM / ISO
testing and certification cost
how to pass certification

认证类保留，但不再是三分天下之一，而是体系里的一个模块。

8. 采购合作 / 供应商评估型集群

回答“怎么和你合作，怎么判断供应商靠不靠谱”。

适合写：

OEM vs ODM
MOQ
lead time
quotation guide
how to evaluate a manufacturer
factory audit checklist
supplier checklist

这个我建议你一定单独拉出来，因为它最接近询盘。
3. 参考来源：Google 自动补全、SEMrush Topic Research、行业论坛问题
4. 标题评估标准：有搜索量、有商业意图、与产品强相关

**产出物**：填写完成的 `templates/article-cluster-research-template.md`

## Step 2：竞对大纲调研 → 撰写自有大纲

**目标**：通过分析竞对内容，制定差异化且更优质的文章大纲。

**操作步骤**：
1. 在 Google 搜索确认好的文章标题（使用目标关键词）
2. 打开前 5 名竞对文章，逐一记录：
   - H1/H2/H3 结构
   - 文章字数（估算）
   - 有无 FAQ、表格、操作步骤
   - 有无案例、数据引用
3. 分析共同点（必须覆盖）和差距（可以超越的点）
4. 撰写自有大纲，要求：
   - 覆盖竞对共同覆盖的核心模块
   - 加入竞对缺失的深度内容（工厂视角、实操案例）
   - 预留 GEO 摘要位置（列表/答案/表格/步骤/FAQ 至少 3 种）

**产出物**：文章大纲草稿（H1 + H2 + H3 + FAQ 问题列表）

---

## Step 3：SEMrush 关键词挖掘

**目标**：从竞对文章中提取可用关键词，优化关键词布局。

**操作步骤**：
1. 在 SEMrush 中输入竞对文章 URL（Organic Research → Pages）
2. 查看该页面排名的所有关键词
3. 筛选条件：
   - 与文章大纲内容匹配
   - 搜索意图一致（信息型 / 商业型）
   - 搜索量 > 100（可根据行业调整）
4. 将关键词分为三类：
   - **主关键词（Primary）**：1 个，出现在标题、H1、首段
   - **次级关键词（Secondary）**：3-5 个，分布在 H2/H3 和正文
   - **LSI/长尾词（Supporting）**：5-10 个，自然融入段落

**产出物**：关键词列表（含搜索量、意图标注）

## Step 4：生成工厂视角 EEAT 素材（ChatGPT 辅助）

**目标**：生成第一人称的工厂经验与项目案例，增强 EEAT 中的 E（Experience）。

**ChatGPT Prompt 结构**：
```
请扮演一名在[行业]工厂有15年经验的工程师/项目经理，
基于以下大纲：[粘贴大纲]
以及以下产品案例链接：[粘贴案例链接]

请输出：
1. 工厂第一视角的实操经验（300字）：描述真实遇到过的[主题相关]问题和解决过程
2. 项目第一人称案例（300字）：描述一个[主题相关]的真实项目经历，包含数据和结果
```

**注意**：
- 产品案例链接需提前在产品页/案例页确认好
- 生成内容需人工核验真实性和专业性
- 作为 EEAT 的 Experience 标记素材备用

**产出物**：工厂视角素材文档（工厂经验段落 + 项目案例段落）

## Step 5：确认内链 + 准备外链引用内容

**目标**：在生成文章前锁定所有链接资源，确保内链和外链质量。

### 5.1 内链规划（先行确认）

| 内链类型 | 锚文本策略 | 来源页面 |
|---|---|---|
| 产品页内链 | 使用产品名称/功能词作为锚文本 | 核心产品落地页 |
| 案例页内链 | 使用行业+场景词作为锚文本 | 案例详情页 |
| 联系页内链 | 使用 CTA 词（"获取报价"等）作为锚文本 | /contact 页面 |
| 同集群文章内链 | 使用相关主题词作为锚文本 | 同集群其他文章 |

### 5.2 外链引用内容准备

外链类型优先级：
1. **行业权威媒体/数据**：引用具体数据或报告结论（需附来源链接）
2. **同行及上下游网站**：引用行业标准或技术规范
3. **Wikipedia**：引用基础概念定义
4. **国际知名案例**：引用大品牌的相关应用场景

**操作**：在 AI 生成文章前，将外链引用内容整理好，以"根据[来源]显示，[引用内容]"的格式准备好段落素材。

**产出物**：内链清单 + 外链引用素材清单

## Step 6：向 AI 输入大纲

**目标**：让 AI 充分理解文章结构，为后续生成做准备。

**操作**：
```
以下是我需要你创作的文章大纲，请先仔细阅读并确认理解：

[粘贴完整大纲，包含 H1/H2/H3/FAQ]

请确认：
1. 你理解了文章的整体逻辑结构
2. 你知道哪些部分需要深度技术内容
3. 你知道哪些部分需要插入工厂经验
回复"已理解大纲"即可，不要开始写文章。
```

## Step 7：输入关键词布局指令 + EEAT 标记指令

**目标**：让 AI 了解关键词分布策略和 EEAT 插入规则。

### 关键词布局指令：
```
关键词布局要求：
- 主关键词"[关键词]"出现在：标题、H1、首段首句、Meta Title
- 次级关键词"[词1][词2]"分别出现在：H2/H3 标题及对应段落首句
- 长尾词自然融入正文，禁止堆砌

语义密度要求：
- 主关键词全文出现 3-5 次
- 次级关键词每个出现 2-3 次
```

### EEAT 标记指令：
```
EEAT 插入规则（请在大纲对应位置标注）：

[E-Experience 经验标记]
插入位置：[指定 H2 章节]
内容：粘贴 Step 4 生成的工厂/项目第一视角经验段落

[E-Expertise 专业标记]
插入位置：[技术细节章节]
内容：引用行业标准、技术参数、工艺对比数据

[A-Authoritativeness 权威标记]
插入位置：[数据/案例章节]
内容：引用权威来源数据 + 外链

[T-Trustworthiness 可信标记]
插入位置：文章结尾/CTA 前
内容：客户评价引用、认证信息、联系方式
```

## Step 8：GEO 文章生成指令

**目标**：生成符合 AI 搜索引擎优化（GEO）要求的内容，包含至少 3 种摘要格式。

### GEO 生成指令：
```
请按以下规则生成文章，字数不少于 2500 字：

【GEO 摘要要求】（必须包含以下至少 3 种）
☑ 列表摘要：在文章开头或适当位置，用 3-7 个要点的列表总结核心内容
☑ 答案摘要：在 H1 下方用 2-3 句话直接回答核心问题（Featured Snippet 格式）
☑ 表格摘要：在对比/参数章节使用 Markdown 表格呈现数据
☑ 操作步骤摘要：在流程章节使用有序列表（Step 1/Step 2...）
☑ FAQ 摘要：文章末尾提供 4-6 个 FAQ，采用问答格式

【文章生成规则】
1. 首段 100 字内直接切入主题，包含答案摘要
2. 每个 H2 章节不少于 200 字
3. 禁止使用"总之""综上所述"等套话开头
4. 数据和事实必须有来源标注
5. EEAT 标记内容按 Step 7 指定位置插入
6. 内链按 Step 5 清单在对应文本处插入
```

## Step 9：WordPress 预览检查

**目标**：上线前完成内容质量验收。

**检查清单**：
- [ ] 字数 ≥ 2500 字（复制到 Word 计数）
- [ ] EEAT 标记内容已正确插入
- [ ] GEO 摘要格式：已包含 ≥ 3 种摘要类型
- [ ] 主关键词出现在：标题、H1、首段、Meta Title
- [ ] H1/H2/H3 层级结构正确
- [ ] 没有关键词堆砌
- [ ] 移动端排版正常
- [ ] 图片 Alt 文本已填写
- [ ] Meta Description ≤ 160 字符

---

## Step 10：配图 + 外链 + 内链

**目标**：补全文章的视觉和链接资源。

### 配图要求：
- 每 500 字至少 1 张图
- 图片类型：产品图、流程图、数据图表、案例照片
- 所有图片添加描述性 Alt 文本（含关键词）
- 文件命名规范：`[keyword]-[description].jpg`

### 外链操作：
- 按 Step 5 清单，在对应文本位置插入外链
- 外链属性设置：`target="_blank" rel="noopener noreferrer"`
- 权威来源链接无需加 nofollow

### 内链操作：
- 按 Step 5 清单，在对应文本位置插入内链
- 确保每篇文章至少包含：产品页内链 × 1、案例页内链 × 1、联系页内链 × 1

## Step 11：添加结构化数据标记

**目标**：通过 Schema Markup 提升搜索结果展示效果。

### 必选标记：

**Article Schema（所有文章）**：
```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "[文章标题]",
  "author": {
    "@type": "Organization",
    "name": "[公司名]"
  },
  "datePublished": "[发布日期]",
  "dateModified": "[修改日期]",
  "publisher": {
    "@type": "Organization",
    "name": "[公司名]",
    "logo": {
      "@type": "ImageObject",
      "url": "[Logo URL]"
    }
  }
}
```

**FAQ Schema（含 FAQ 的文章）**：
```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "[FAQ 问题]",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "[答案内容]"
      }
    }
  ]
}
```

**HowTo Schema（含操作步骤的文章）**：
```json
{
  "@context": "https://schema.org",
  "@type": "HowTo",
  "name": "[步骤标题]",
  "step": [
    {
      "@type": "HowToStep",
      "name": "Step 1",
      "text": "[步骤内容]"
    }
  ]
}
```

**ImageObject Schema（含关键图片的文章）**：
```json
{
  "@context": "https://schema.org",
  "@type": "ImageObject",
  "url": "[图片 URL]",
  "description": "[图片描述]",
  "width": "[宽度]",
  "height": "[高度]"
}
```

## 流程总览

```
Step 1  调研集群标题
   ↓
Step 2  竞对大纲 → 自有大纲
   ↓
Step 3  SEMrush 关键词挖掘
   ↓
Step 4  GPT 生成 EEAT 素材（工厂/项目视角）
   ↓
Step 5  确认内链清单 + 外链引用素材
   ↓
Step 6  向 AI 输入大纲
   ↓
Step 7  输入关键词布局 + EEAT 标记指令
   ↓
Step 8  GEO 文章生成（≥2500字，≥3种摘要）
   ↓
Step 9  WordPress 预览质量检查
   ↓
Step 10 配图 + 外链 + 内链
   ↓
Step 11 添加结构化数据（Article/FAQ/HowTo/Image）
   ↓
Step 12 填写关键词词表归档
```
