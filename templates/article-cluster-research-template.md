# 这 8 个文章集群怎么理解

你原来那套 3 分类，其实更像是一个“粗分类版本”：

* 产品型
* 工程类
* 认证类

现在这套 8 分类，是把它进一步拆细了，逻辑会更清楚：

| 原来的分类          | 现在对应的新分类                                 |
| -------------- | ---------------------------------------- |
| 产品型文章集群        | 认知教育型、选型决策型、对比替代型、应用场景/解决方案型、采购合作/供应商评估型 |
| 工程类文章集群        | 规格标准型、工艺质量/问题排查型                         |
| 认证类文章集群        | 认证合规型                                    |
| 原来没有单独拆出的高转化模块 | 采购合作/供应商评估型                              |

所以你现在这套模板，已经比之前更适合：

* **做SEO集群**
* **做B2B询盘路径**
* **做内链系统**
* **做AI工作流分工**

# 你后面填这个模板时，建议再多加 3 列

如果你想把这个模板直接升级成可执行版本，我建议你再增加这 3 列：

| 新增列    | 用途                           |
| ------ | ---------------------------- |
| 目标页面类型 | 博客 / 支柱页 / 对比页 / 解决方案页 / 服务页 |
| 对应内链去向 | 链接到哪个产品页 / 服务页 / 认证页 / 联系页   |
| 商业价值等级 | 引流型 / 养熟型 / 转化型              |

这样你后面就不会只是“收集标题”，而是能直接判断：

* 这篇文章值不值得写
* 这篇文章写完要导向哪里
* 它是负责拉流量，还是负责转化
