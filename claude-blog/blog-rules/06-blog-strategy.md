# /blog strategy — 博客战略规划

制定全面博客战略，构建 Google 排名的话题权威，同时在 AI 引用平台建立品牌存在。包含话题簇架构、AI 引用曝光战略、内容评分目标和 GEO 优化计划。

---

## 8步工作流

### Step 1：发现

通过问题或项目分析收集上下文：

1. **业务**：你卖什么/做什么？客户是谁？
2. **博客目标**：流量？线索？权威性？AI 引用？
3. **现状**：现有博客内容？（如有项目则扫描）
4. **竞争对手**：主要竞争对手 3-5 家
5. **差异化**：你有什么独特专业知识或数据？
6. **资源**：写作能力（篇/周），视觉预算？

---

### Step 2：竞争格局分析

研究竞争对手博客：
1. WebSearch 找竞争对手博客 URL
2. 每个竞争对手评估：
   - 发布频率
   - 内容类型（指南、案例研究、比较、新闻）
   - 视觉质量（图片、图表、视频）
   - Schema 使用
   - 社交分发（YouTube、Reddit、LinkedIn）
   - AI 引用存在（搜索 ChatGPT/Perplexity 的行业词）
3. 识别无竞争对手覆盖好的差距

#### 竞争对手 AI 引用地图

```
## 竞争对手 AI 引用地图
| 查询词 | ChatGPT 引用 | Perplexity 引用 | AI Overview 引用 | 差距？ |
|--------|------------|----------------|-----------------|--------|
| [关键词] | [竞争对手/无] | [竞争对手/无] | [竞争对手/无] | [是/否] |
```

AI 可见度评分：
- **高**：在 3/3 平台的多个查询中被引用
- **中**：在 1-2 个平台或有限查询中被引用
- **低**：很少被引用，仅在小众查询中
- **无**：未检测到 AI 引用存在

识别 AI 引用差距 — 无竞争对手被引用的查询，这些是新内容的最高机会目标。

> **注**：平台间只有 12% 的重叠 — 在 ChatGPT 强势的竞争对手可能在 Perplexity 缺席。需分平台独立分析。

### Step 4：内容支柱设计（Hub-and-Spoke 架构）

设计 3-5 个内容支柱，为每个支柱建立完整的 Hub-and-Spoke 架构：

```
### 支柱：[话题领域]
- **目的**：在 [话题] 中建立权威
- **主关键词**：[3-5 个关键词]
- **内容类型**：支柱指南、支持文章、比较文章、FAQ
- **独特角度**：[你能提供什么第一手经验/数据？]
- **预计文章数**：[N] 篇实现全面覆盖
- **AI 引用潜力**：[高/中/低] — [原因]
```

#### 簇架构设计

```
### 簇架构：[支柱话题]

                    ┌──────────────────┐
                    │   支柱页面       │
                    │   3000-4000字    │
                    └────────┬─────────┘
                             │
           ┌─────────────────┼──────────────────┐
           │                 │                   │
    ┌──────▼──────┐   ┌─────▼──────┐   ┌───────▼──────┐
    │  辐射文 #1  │   │  辐射文 #2 │   │  辐射文 #3   │
    │  1500-2500  │   │  1500-2500 │   │  1500-2500   │
    └──────┬──────┘   └─────┬──────┘   └───────┬──────┘
           │                │                   │
           └────────────────┼───────────────────┘
                    （辐射文之间交叉链接）
```

**每个簇规划：**

| # | 辐射文话题 | 模板 | 目标关键词 | 字数 | 内链 |
|---|---------|------|---------|------|------|
| P | [支柱标题] | pillar-page | [关键词] | 3000-4000 | 链接到所有辐射文 |
| 1 | [辐射文标题] | how-to-guide | [关键词] | 1500-2500 | 支柱 + 辐射文2,3 |
| 2 | [辐射文标题] | comparison | [关键词] | 1500-2500 | 支柱 + 辐射文1,3 |
| 3 | [辐射文标题] | listicle | [关键词] | 1500-2500 | 支柱 + 辐射文1,2 |

每个支柱规划 **8-12 个辐射话题**。

### Step 5：差异化战略

2025年12月核心更新奖励第一手经验。规划如何展示真实专业知识：

| 信号类型 | 实现方式 |
|---------|---------|
| 原始数据 | 开展调查、分析专有数据、运行实验 |
| 案例研究 | 记录有指标的真实客户/项目结果 |
| 公开构建 | 透明分享过程、经验和失败 |
| 专家访谈 | 邀请有第一手知识的从业者 |
| 工具评测 | 亲身测试产品，分享截图和结果 |
| 行业分析 | 对公开数据提供独特视角 |

### Step 5.5：AI 引用曝光战略

**关键数据**：80% 的 LLM 引用来自 Google 有机结果前 100 之外 — 仅靠传统 SEO 不够。

#### 站内优化

- 每个 H2 以答案优先段落开头（40-60字，含统计+来源）
- **引用胶囊**：每个 H2 部分 40-60 字独立可引用文字
- **问答格式**：60-70% H2 为问题格式
- 每篇文章都有带 Schema 的 **FAQ 部分**
- **实体清晰度**：关键概念术语一致（不使用同义词变体）
- **结构化数据**：Article、FAQ、HowTo、Review Schema

#### 站外存在（关键 — 88-92% AI 引用来自站外）

| 渠道 | AI 引用影响 | 优先行动 |
|------|-----------|---------|
| YouTube | 0.737 相关性（最强） | 为支柱文章制作配套视频 |
| Reddit | 450% 引用激增 | 在 3-5 个版块真实参与 |
| 评测平台 | 2.6-3.5 倍乘数 | 维护 G2、Capterra（B2B）资料 |
| Wikipedia/Wikidata | 可信度决定者 | 建立知名度，创建 Wikidata 条目 |
| 行业媒体 | Tier 2-3 引用来源 | 客座文章、专家评论 |

#### 跨平台监测

- 每月追踪 ChatGPT、Perplexity、Google AI Overviews 的品牌提及
- 平台间仅 12% 重叠 — 分平台独立优化
- 每月监测：在每个平台搜索 10-20 个目标查询，记录引用情况

### Step 5.6：内容评分目标

所有博客内容必须达到的质量标准：

| 指标 | 目标 | 测量工具 |
|------|------|---------|
| 博客质量分 | 80+ | `/blog analyze` |
| E-E-A-T 合规 | 命名作者 + 8+ Tier 1-3 来源 | 人工审查 |
| AI 引用就绪度 | 答案优先 + FAQ + 引用胶囊 | `/blog analyze` |
| 视觉最低标准 | 每篇 2+ 图表 + 3+ 图片 | 资源统计 |
| 内链 | 每篇 5+ 个（簇内） | 链接审计 |
| Schema 标记 | 文章 + FAQ + 相关类型 | 结构化数据测试 |
| 字数 | 辐射文 1500+，支柱文 3000+ | 字数工具 |

**发布前每篇文章都要评分。质量分低于 80 的文章在上线前需要修改。**

---

### Step 5.7：GEO 平台专项战略

| AI 平台 | 偏好 | 优化重点 |
|---------|------|---------|
| ChatGPT | 近期内容、品牌权威、对话清晰度 | 30天内更新，清晰的实体定义 |
| Perplexity | 引用、来源多样性、结构化回答 | Tier 1-3 来源，数字列表，数据表 |
| Google AI Overviews | 结构化数据、Schema、话题权威性 | FAQ Schema，完整话题簇覆盖，精选摘要格式 |

- **ChatGPT**：确保品牌名一致出现，保持 30 天新鲜度，使用对话式答案优先格式
- **Perplexity**：最大化外部引用数（每篇 8+），使用结构化数据表，引用权威来源
- **AI Overviews**：完整话题簇覆盖，实现所有相关 Schema 类型，达到精选摘要格式

### Step 7：衡量框架

#### 传统 SEO 指标
- 自然流量（月度）
- 关键词排名（前10、前3）
- 域名权重 / Domain Rating
- 内链覆盖
- Core Web Vitals

#### AI 引用指标（新）
- ChatGPT 回应中的品牌份额（人工追踪）
- AI Overview 引用率（Google Search Console）
- Perplexity 提及（人工追踪）
- AI 推荐流量（GA4：来源含 chatgpt、perplexity、claude）
- 品牌提及量（品牌词搜索 + 网络提及）

#### 内容质量
- 通过 `/blog analyze` 得到的博客质量分（目标：80+）
- 内容新鲜度（30天内更新的文章比例）
- 视觉元素覆盖（每篇文章的图表+图片数量）
- 引用来源质量（Tier 1-3 来源比例）

#### 业务影响
- 博客带来的线索/转化
- 博客邮件订阅者
- 内容辅助收入
