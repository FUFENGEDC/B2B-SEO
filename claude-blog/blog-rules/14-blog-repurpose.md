# /blog repurpose — 跨平台内容再利用

将博客文章转化为各平台优化内容：社交媒体、邮件、视频和社区频道。每种输出根据平台规范和受众期望调整语气、格式和长度。

---

## 8步工作流

### Step 1：读取并分析

读取博客文章，提取核心内容元素：
- **标题**：原始博客文章标题
- **关键洞察**（5-7条）：最重要的要点，每条作为独立陈述
- **统计数据**：所有有来源归因的数据点
- **引语**：任何值得注意的引用或专家陈述
- **主论点**：1-2句核心论题
- **TL;DR**：2-3句传递独立价值的摘要
- **目标受众**：博客写给谁
- **话题类别**：用于版块和话题标签选择

### Step 2：询问用户

提示用户选择要生成的平台：
1. Twitter/X 线程
2. LinkedIn 文章
3. YouTube 视频脚本
4. Reddit 讨论帖
5. 邮件通讯摘录
6. 全部

如果用户直接指定平台，跳过此步骤。

---

### Step 3：Twitter/X 线程

生成完整的参与度优化线程：

**钩子推文（第1条）：**
- 以好奇心缺口或大胆统计开头
- 不超过 280 字符
- 让人停止滑屏
- 模式：`[惊人统计或反常识观点]。[受众]需要知道的内容：`

**洞察推文（第2-6条）：**
- 每条一个关键点，每条独立有价值
- 尽量含有来源统计
- 用换行增加可读性
- 每条单独阅读也能理解

**结尾推文（最后一条）：**
- 一句话总结核心要点
- 含明确 CTA 链接到完整文章
- 添加相关话题标签（每条最多 2 个）
- 模式：`完整分析：[链接]\n\n#标签1 #标签2`

**线程格式规则：**
- 推文编号：1/、2/ 等，清晰明了
- 每条不超过 280 字符
- 线程长度：总共 7-9 条
- 语气：对话式、直接、洞察密集

---

### Step 4：LinkedIn 文章

为 LinkedIn 专业受众和格式改编博客：

**长度：** 800-1200 字（比博客更短）

**开头**（"查看更多"前可见的前 2-3 行）：
- 以个人故事、观察或反常识观点开头
- 这是钩子 — 必须让人点击"查看更多"
- 绝不以"很高兴分享..."或类似套话开头

**正文结构：**
- 使用 LinkedIn 原生格式：重点词加粗，单行段落，段落间宽行距
- 关键要点使用编号列表
- 短段落（1-3句）
- 含 2-3 条有来源的关键统计
- 比原博客更个人化、更有观点导向

**结尾：**
- 以引发评论的互动问题结尾
- 模式：`你在 [话题] 上有什么经历？很想在评论区听到你的想法。`
- 正文中**不放外链**（LinkedIn 对此降权）
- 在第一条评论中放博客链接（在输出中注明）

**语气：** 专业但对话式。第一人称视角。分享你学到的或观察到的，不只是数据说什么。

---

### Step 5：YouTube 脚本

生成为留存优化的完整视频脚本：

**钩子**（0-15秒）：
- 来自博客最强洞察的大胆陈述或惊人问题
- 模式：`你知道 [震惊统计] 吗？今天我要告诉你 [承诺]。`
- 必须在观众点击离开前抓住注意力

**简介**（15-60秒）：
- 观众将学到什么（3个要点）
- 为什么现在重要
- 简短的可信度陈述
- `[显示标题卡]`

**主要内容**（3-5个谈话点）：
- 从博客的 H2 部分衍生
- 每个部分：关键点、支持数据、实际例子
- 全程含视觉提示：
  - `[显示图表：描述]` — 数据可视化
  - `[切换到屏幕录制]` — 演示
  - `[B-roll：描述]` — 视觉多样性
  - `[屏幕文字：关键统计]` — 强调
- 部分间有过渡语句

**CTA**（最后15-30秒）：
- 订阅提示（含理由）
- 视频描述中链接到完整博客
- 预告下一个相关视频话题

**脚本元数据：**
- 基于字数的预计时长（~150字/分钟）
- 建议标题（60字符内，含关键词）
- 建议缩略图概念（文字 + 视觉）
- 含时间戳、博客链接和关键要点的描述

---

### Step 6：Reddit 帖子

将博客内容重构为真实的社区讨论：

**版块建议：**
- 推荐 2-3 个相关版块（基于博客话题）
- 考虑版块规模、规则和发帖惯例
- 检查版块是否允许链接或倾向纯文字帖

**帖子格式：**
- 标题：以问题或观察切入，不是博客推广
  - 好：`分析 500 个活动后，这是真正驱动 ROI 的因素`
  - 差：`看我关于营销 ROI 的新博客文章`
- 以问题或有趣观察开头
- 以向同行汇报结果的方式分享关键发现
- 使用 Reddit Markdown 格式（标题、项目符号、加粗）
- 含 3-5 个有来源的数据点
- 以讨论提示结尾：`其他人也看到类似结果吗？`

**自我推广合规：**
- 遵守 10% 规则：自我推广内容最多占发帖的 10%
- 绝不用标题党或误导性标题
- 帖子本身提供真正价值 — 读者无需点击链接也能受益
- 在末尾自然放博客链接：`含图表的完整分析：[链接]`

**语气：** 同行对等，谦逊，讨论导向。绝不推销。

---

### Step 7：邮件通讯摘录

生成简洁的邮件参与度优化通讯栏目：

**主题行：**
- 40-60 字符
- 好奇心驱动或价值驱动（非标题党）
- 模式选项：
  - 好奇心：`没人追踪（但应该追踪）的 [话题] 指标`
  - 价值：`来自 [来源/研究] 的 [N] 个 [话题] 洞察`
  - 紧迫性：`[话题] 本月有变化。该怎么做。`

**预览文字：**
- 40-90 字符，补充（不重复）主题行
- 在收件箱主题行后显示 — 视为第二个标题

**正文：**
- **TL;DR**（2-3句）：含关键要点的独立摘要
- **3条关键要点**（项目符号）：每条含统计和来源
- **CTA**：链接到完整博客文章的清晰链接
  - 按钮文字："阅读完整分析"或类似行动导向短语

**总长度：** 150-200 字。每个词都要挣得它的位置。

**格式：**
- 短段落（1-2句）
- 重点短语加粗（方便扫读）
- 单一 CTA（不与多个链接竞争）

---

### Step 8：保存

将所有生成的输出保存到 `repurposed/` 目录：

```
repurposed/
  {slug}-twitter-thread.md
  {slug}-linkedin-article.md
  {slug}-youtube-script.md
  {slug}-reddit-post.md
  {slug}-email-newsletter.md
```

如 `repurposed/` 目录不存在，先创建。

保存后呈现摘要：

```
## 再利用内容：[博客标题]

### 生成的输出
- Twitter/X 线程：repurposed/{slug}-twitter-thread.md（X 条推文）
- LinkedIn 文章：repurposed/{slug}-linkedin-article.md（约 X 字）
- YouTube 脚本：repurposed/{slug}-youtube-script.md（约 X 分钟）
- Reddit 帖子：repurposed/{slug}-reddit-post.md（建议 X 个版块）
- 邮件摘录：repurposed/{slug}-email-newsletter.md（约 X 字）

### 快速统计
- 提取的关键洞察：X 条
- 跨平台复用的统计：X 条（跨 Y 个平台）
- 内容片段总数：X 个

### 后续步骤
- 审阅并根据品牌声音定制每个片段
- 用你偏好的社交媒体工具安排发布
- Twitter：在高峰时段发帖（早9-11点或下午1-3点，当地时间）
- LinkedIn：周二至周四发布，参与度最高
- Reddit：在美国上午时段发布（东部时间早8-10点）
```
